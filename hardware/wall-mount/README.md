# Uchwyt ścienny

Ten katalog przechowuje mechaniczną część WallDeck: modele źródłowe CAD, eksporty do druku, rysunki, listę elementów i instrukcję montażu.

## Założenia

- tablet można zdjąć bez narzędzi;
- mocowanie nie naciska ekranu ani przycisków;
- przewód USB-C jest wymienny i ma odciążenie mechaniczne;
- otwory wentylacyjne pozostają drożne;
- magnesy mają mechaniczne gniazda i nie są jedyną ochroną przed zsunięciem;
- projekt uwzględnia tolerancje druku i miękkie podkładki stykające się z tabletem.

## Planowane pliki

```text
cad/       źródła parametryczne, np. Fusion 360/STEP
exports/   STL/3MF/PDF gotowe do użycia
drawings/  rysunki wymiarowe
photos/    zdjęcia prototypów bez danych osobowych
```

Przed rozpoczęciem modelowania trzeba zapisać dokładny model tabletu, wymiary obudowy, pozycję USB-C, grubość używanej osłony oraz geometrię miejsca montażu.

Aktualna [lista elementów](BOM.md) jest robocza. Zrzuty sklepów z nazwą konta i lokalizacją nie są przechowywane w publicznym repozytorium.
